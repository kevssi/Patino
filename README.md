# Patiño - Sistema de Restaurante

Proyecto integral para gestión de restaurante con backend en **Django REST Framework** y frontend en **React + Vite**.

## Estructura del Proyecto

- `backend/`: API desarrollada con Django REST Framework y documentación Swagger/OpenAPI.
- `frontend/`: Interfaz de usuario interactiva desarrollada con React, Vite y Semantic UI React.

## Requisitos

- Python 3.10+
- Node.js 18+

## Puesta en marcha

### Backend (Django)
```bash
cd backend
.\venv\Scripts\activate   # En Windows
python manage.py runserver
```
Servidor backend: `http://127.0.0.1:8000/`  
Documentación Swagger: `http://127.0.0.1:8000/swagger/`

### Frontend (React / Vite)
```bash
cd frontend
npm install
npm run dev
```
Servidor frontend: `http://localhost:5173/`
